## 🔄 How It Works

```
User Flow:
    App Startup → Load saved configuration
              ↓
    User clicks printer icon → Open setup dialog
              ↓
    User clicks "Configure Categories" → Open selection dialog
              ↓
    User assigns categories → Visual feedback
              ↓
    User clicks "Save" → Saves to device storage
              ↓
    Configuration remembered → On app restart

Printing Flow:
    User prints order → Load saved categories
              ↓
    Create router with dynamic categories → Route items
              ↓
    Falafel items → Falafel printer
    Shawarma items → Shawarma printer
    Receipt → Customer printer
```
